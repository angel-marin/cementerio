# La noche del enterrador

Escape room en primera persona para el navegador, hecho con Babylon.js.

Controles en ordenador: WASD para moverte, ratón para mirar, clic o E para interactuar.
Controles en móvil: joystick a la izquierda, arrastra a la derecha para mirar y botón Usar.

Es una sola página (`index.html`) con el modelo del niño incrustado. Babylon.js se carga desde jsDelivr.
